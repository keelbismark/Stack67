# Stack67

Страница-раздача модпака Stack67 для Minecraft: готовая сборка под три загрузчика (Fabric, NeoForge, Spigot/Paper) плюс датапак-вариант без модов. Исходники лежат внутри репозитория только в виде zip-архивов.

Это не репозиторий кода, а витрина готовых артефактов: модифицировать модпак средствами GitHub здесь нельзя, для этого нужно распаковать `*-src.zip`.

## Возможности

- Статическая страница `index.html` со скачиванием сборок в один клик
- Три сборки мода под Minecraft 1.21.1:
  - Fabric — v1.2.0
  - NeoForge — v1.2.0
  - Spigot / Paper — v1.0.0
- Датапак v1.1.0 для Minecraft 1.20.5+ — вариант «без модов, просто кинь в папку»
- Исходники каждой сборки выложены отдельными zip-архивами
- Иконка проекта `icon.png`

Состав датапака (по содержимому `Stack67-Datapack.zip`): `pack.mcmeta`, `pack.png`, функции и теги в `data/stack67/` и `data/minecraft/tags/function/` (`tick.json`, `load.json`), достижения, например `apply_stack_67.json`.

## Стек

- Minecraft 1.21.1: Fabric, NeoForge, Spigot/Paper
- Датапак для Minecraft 1.20.5+
- Статическая вёрстка на чистом HTML и встроенном CSS, шрифт Inter с Google Fonts

Сборочных скриптов в репозитории нет: ни Gradle, ни Fabric/neoforge-конфигурации, ни папки `src/`. Пересборка модов из исходников выполняется вне этого репозитория.

## Установка и запуск

Сборка не требуется — это готовые файлы. Страницу можно открыть локально:

```bash
# любой статический сервер в корне репозитория
python -m http.server 8000
# затем открыть http://localhost:8000
```

Установка модпака на сервер Minecraft:

- **Fabric / NeoForge** — положить соответствующий `.jar` в папку `mods/`
- **Spigot / Paper** — положить `stack67-spigot-1.0.0.jar` в папку `plugins/`
- **Датапак** — распаковать `Stack67-Datapack.zip` в папку `worlds/<мир>/datapacks/`

## Структура проекта

- `index.html` — единственная страница-витрина со всеми кнопками скачивания
- `stack67-fabric-1.2.0.jar` — сборка для Fabric
- `stack67-neoforge-1.2.0.jar` — сборка для NeoForge
- `stack67-spigot-1.0.0.jar` — сборка для Spigot / Paper
- `Stack67-Datapack.zip` — готовый датапак (версия 1.1.0)
- `stack67-fabric-src.zip`, `stack67-neoforge-src.zip`, `stack67-spigot-src.zip` — исходники модов
- `stack67-datapack-src.zip` — исходники датапака
- `icon.png` — иконка проекта, используется в шапке страницы и как favicon
